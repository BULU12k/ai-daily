百度开源文心5.5 Flash Base

11月5日，百度开源基座模型文心5.5 Flash Base（ERNIE 5.5 Flash Base），权重已上传至 Hugging Face。 模型采用 MoE 架构，总参数2800亿，每个 Token 激活140亿参数，预训练用了33.5万亿 Token，预训练上下文最长128K，微调与推理阶段支持最长100万 Token。 百度称其在知识、推理、数学、代码、多语言和长上下文等多个基准上取得同尺寸模型 SOTA，超过 DeepSeek-V4-Flash-Base、Hy3-preview-Base、MiMo-V2.5-Base 等；该对比为厂商自述，尚待第三方复现。 架构上，模型采用 Latent-Gated Sparse Attention，组合 HCA 与 MLA 分别负责压缩历史信息和细粒度访问历史位置，低秩门控注意力使门控投影权重参数减少75%；专家路由采用 Multi-Router Latent MoE，并以单步 ECHO 复用主干最后一层做后续 token 预测，该层还可充当投机解码草稿模型。

MIT Astra研究被指误导性呈现

MIT 团队此前宣称，Astra 无需训练和梯度，仅修改 Qwen3.5-0.8B 的0.016%权重，就使其数学成绩从7.9%升至48.1%，约为原来的6倍，引发刷屏。 spaCy 作者、Explosion 联合创始人 Matthew Honnibal 随后发文质疑该研究存在严重误导。 他梳理论文8组实验后指出，识别小型网络、修复卡住的赛车模型等实验确实只输入原始权重数字，但条件极苛刻：禁止运行 Python 代码，禁止执行目标网络观察行为，参数规模仅1.7万至17.2万。 而在最受关注的 Qwen 修复实验中，Astra 并未直接读取原始权重，而是被允许编写 Python 并最多进行50次前向测试，通过观察模型表现来分析和改权重。 Honnibal 认为，论文摘要把两类能力包装成统一的“读懂并改写模型大脑”，容易让人误以为小模型上的读权重能力可规模化用于大模型。 他同时承认，让模型自行编写代码诊断和修改另一模型权重本身是重要进步，一两年前的模型在这些任务上都会失败，问题出在成果呈现方式。

GPT挖出Linux内核948个提权漏洞

OpenAI称其动用一款尚未发布的「网络安全模型」配合多智能体流水线，用约10天对Linux内核完成自动化漏洞挖掘，最终确认948个可本地提权至root的独立漏洞，总花费约120万美元，平均单个漏洞成本1279美元。 流程分三步：侦察兵从4000多万行代码中圈出约280万行（约7%）安全相关代码，耗3426美元API额度；分析师12小时内提交2308份疑似漏洞报告，耗资31.6万美元；分类兵30小时内在隔离环境复现1724个内核崩溃，命中率74.7%、纯误报3.1%；利用开发智能体产出291个信息泄露PoC与1169个root提权利用，平均每个可用利用成本359美元。 OpenAI称模型自行发现至少10种新的内核攻击技术，200个案例中有20个未使用指定漏洞、而是自行找到新0-day完成提权。 作为对比，此前人类研究员一年约发现20个同类漏洞。 上述数字均出自OpenAI自述，尚待第三方复核；文中提到社区已在扫描窗口内上游修补61个相关漏洞。
